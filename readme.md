# IX-Ray New Quest Addon — исправленный комплект

Установка: полностью заменить прежнюю папку аддона в ixr_addons игры «Зов Припяти» на IX-Ray. Перезапустить игру полностью.
Поддерживаются русская и английская локализации. Сюжетные условия выдачи поручения Бороды сохранены.

Исправлены инициализация callbacks, сохранение идентификаторов объектов через pstor, повторный спавн,
передача документов Хмурому, восстановление документов для старых сохранений, подключение диалогов
к Бороде, Лоцману и Сычу. Добавлены отсутствующие профили NPC и тексты. Координаты из версии 1.0 сохранены.
Стандартные Lua-модули и общий список спавна не заменяются.

Новые тексты и описание NPC восстановлены по имеющимся веткам квеста: оригинальных недостающих файлов в комплекте не было.

Проверка в игре:
1. Новая игра и загрузка старого сохранения без задания: получить поручение Бороды.
2. Открыть отмеченный тайник; забрать документы; сохранить и загрузить игру.
3. Проверить Хмурого и обоих охранников: спавн должен произойти один раз.
4. Проверить отказ, обе сделки с Хмурым и получение документов с его тела.
5. Проверить возврат Бороде и альтернативную продажу Сычу после разговора с Лоцманом.
6. Проверить переход на другую локацию и возврат на Затон при активном задании.

Lua и XML проверены отдельно от игры. Реальные координаты AI-сетки, модели и прохождение требуют проверки в установленной игре.
Если остаётся nil для dialog_manager/xr_logic/xr_conditions при запуске, нужен полный лог и проверка базовой gamedata: этот аддон их не заменяет.

Исправление совместимости:
- Диалоги добавлены в character_desc_zaton.xml напрямую: старый XMLOverride не выбирает specific_character по id.
- Файл сохраняет всех персонажей и включения базового character_desc_zaton.xml из установленной игры.
  При объединении с другими аддонами, которые заменяют тот же файл, нужно совместить изменения.
- Используются callbacks update/load, поддерживаемые старыми и новыми сборками.
- Скрипт запускается при загрузке своего модуля и через сохранённый functor активного задания.
- Реплика выдачи: «Борода, есть поручение с документами?»; она открывается после задания с необычным артефактом.

Диагностика: в логе должна быть строка [bq] Quest callbacks initialized после открытия разговора с Бородой.
