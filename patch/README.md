# Патч движка (обязателен для работы мода)

> [!IMPORTANT]
> **Без этого патча мод работает не полностью.** Иконки заполненных контейнеров
> не будут показывать, какой артефакт внутри — они будут выглядеть так же, как
> пустые. Всё остальное (квест, контейнеры, механика складывания) работает и без
> патча.

## Что это

Мод показывает содержимое контейнера: поверх иконки контейнера рисуется маленькая
иконка лежащего в нём артефакта. Штатный движок IX-Ray так не умеет — в нём нет
поддержки «слоёв» иконок. Поэтому мод поставляет **собранные файлы движка** с
добавленной поддержкой слоя-иконки.

## Что в этой папке

Файлы движка (`.exe` и `.dll`) с патчем. Их нужно положить в папку **`bin`** игры,
заменив существующие.

> Список файлов появится здесь после релизной сборки. Сейчас (на этапе тестов)
> используется debug-сборка движка, файлы в папку пока не выложены.

## Установка

1. Установите мод как обычно (скопируйте папку `zzz-ixray-new-quest-addon-v1.1`
   в `ixr_addons`).
2. Скопируйте **все** файлы из этой папки (`patch/`) в папку **`bin`** игры
   с заменой существующих.
3. Играйте.

## Откат

Чтобы вернуть штатный движок, восстановите файлы в `bin` из резервной копии
(сделайте её перед установкой патча).

## Примечания

- Патч собран из исходников IX-Ray с минимальными правками, только для поддержки
  слоя-иконки. Описание правки — в файле `ENGINE_PATCH_icon_layer.cpp.txt`
  в корне аддона.
- Патч нужно обновлять при обновлении движка IX-Ray.
