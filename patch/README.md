# Патч движка (обязателен для работы мода)

> [!IMPORTANT]
> **Без этого патча мод работает не полностью.** Иконки заполненных контейнеров
> не будут показывать, какой артефакт внутри — они будут выглядеть так же, как
> пустые. Всё остальное (квест, контейнеры, механика складывания) работает и без
> патча.

## Что это

Мод показывает содержимое контейнера: поверх иконки контейнера рисуется маленькая
иконка лежащего в нём артефакта. Штатный движок IX-Ray так не умеет — в нём нет
поддержки «слоёв» иконок. Поэтому мод поставляет **собранные файлы движка** с
добавленной поддержкой слоя-иконки.

Сборка сделана из исходников [IX-Ray 1.6 для S.T.A.L.K.E.R. CoP](https://github.com/ixray-team/ixray-1.6-stcop)
с одной небольшой правкой. Описание правки — в файле
[`ENGINE_PATCH_icon_layer.cpp.txt`](../ENGINE_PATCH_icon_layer.cpp.txt) в корне аддона.

## Установка

1. Скопируйте **все** файлы из этой папки в папку **`bin`** игры с заменой
   существующих.
2. Готово. Мод (`zzz-ixray-new-quest-addon-v1.1`) устанавливается как обычно —
   в папку `ixr_addons`.

> Перед заменой рекомендуется сохранить исходные файлы из `bin` — чтобы была
> возможность откатиться.

## Состав патча

Заменяются **16 файлов** (остальные файлы в `bin` трогать не нужно):

| Файл | Размер, КБ |
|---|---|
| `imgui.dll` | 1261,5 |
| `luabind.dll` | 118 |
| `SDL3.dll` | 2575 |
| `xrAbstractions.dll` | 920,5 |
| `xrCore.dll` | 1515 |
| `xrEngine.exe` | 1226 |
| `xrGame.dll` | 9701,5 |
| `xrNetServer.dll` | 78 |
| `xrParticles.dll` | 131 |
| `xrPhysics.dll` | 579,5 |
| `xrRender_R1.dll` | 1065,5 |
| `xrRender_R2.dll` | 1177 |
| `xrRender_R4.dll` | 1467 |
| `xrScripts.dll` | 679,5 |
| `xrSound.dll` | 147 |
| `xrUI.dll` | 791 |

Суммарно около **23 МБ**.

**Почему меняются не только `xr*`-файлы:** движок собран целиком, и модули
(`xrGame.dll`, `xrCore.dll` и т.д.) должны быть одной сборки, иначе возможны
несовместимости. Файлы `imgui.dll`, `luabind.dll`, `SDL3.dll` — это зависимости
движка, они тоже входят в сборку.

**Что НЕ входит в патч:** остальные файлы игры (в том числе `lua51.dll`,
`libogg.dll`, `libtheora.dll`, `OpenAL32.dll` и прочие сторонние библиотеки)
в нашей сборке получились **байт-в-байт такими же**, как в штатной игре, поэтому
их заменять не нужно.

## Откат

Чтобы вернуть штатный движок — восстановите ранее сохранённые файлы из `bin`.

## Примечания

- Патч собран из исходников IX-Ray с минимальной правкой — только поддержка
  слоя-иконки. Никакой другой логики в движок не добавлено.
- **В этой сборке нет отладочного меню и меню спавнера.** Они есть только в
  debug-сборках движка: в release-конфигурации определяется `MASTER_GOLD`,
  который их отключает. На геймплей это не влияет.
- При обновлении движка IX-Ray патч нужно собрать заново и обновить.
